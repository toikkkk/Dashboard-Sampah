## Overview

**Jejak Sampah** is a web-based environmental data analytics platform designed to provide insights into waste management conditions across Indonesia.

The platform transforms waste management data into interactive visualizations and analytical insights, helping users understand waste generation patterns, waste management performance, regional differences, and waste composition.

Powered by SIPSN 2025 data, Jejak Sampah aims to improve public awareness of environmental issues and support data-driven decision-making for more sustainable waste management.

**Live Website:** https://www.jejaksampah.my.id/

---

## Key Features

### 1. Interactive Waste Analytics Dashboard
- Visualize waste generation across Indonesia.
- Compare managed and unmanaged waste.
- Explore waste management statistics through interactive charts.
- Monitor environmental indicators.

### 2. Regional Analysis
- Explore waste management conditions across different regions.
- Search and filter regional data.
- Compare waste management performance between regions.

### 3. Regional Clustering Analysis
- Group regions based on waste management characteristics.
- Identify similarities and differences in regional waste conditions.
- Provide analytical insights into regional waste management patterns.

### 4. Waste Composition & Sources
- Analyze waste composition categories.
- Explore different sources of waste generation.
- Understand waste distribution and characteristics.

### 5. Regional Rankings
- Display regional rankings based on waste management indicators.
- Identify regions with different levels of waste management performance.

### 6. AI-Powered Data Chatbot
- Interact with waste management data using natural language.
- Ask questions about environmental statistics.
- Obtain insights and information through conversational interaction.

## Data Source

The platform utilizes waste management data from:

- **SIPSN (Sistem Informasi Pengelolaan Sampah Nasional)**
- Data reference: 2025
- Coverage: Indonesia

The data is used to support statistical analysis, regional comparisons, visualization, and environmental insights.
